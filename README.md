# Financial Forecasting with ARIMA, Gradient Boosting, and LSTM

**Companion Python implementation for the research article:**  
*An Applied Comparison of LSTM, Gradient Boosting, and ARIMA for Financial Forecasting*

## Overview

This repository provides a Google Colab notebook implementing a chronological forecasting and evaluation pipeline for three U.S. stock-market indices. It compares univariate ARIMA, gradient boosting machine (GBM), and a two-layer long short-term memory (LSTM) network.


## Study configuration

| Component | Configuration |
| --- | --- |
| Indices | S&P 500 (`^GSPC`), Dow Jones Industrial Average (`^DJI`), NASDAQ Composite (`^IXIC`) |
| Target | Future daily closing **index level** |
| Forecast horizons | 1, 5, 10, and 20 trading sessions |
| Lookback window (GBM/LSTM) | 60 trading sessions |
| Training | 2013–2019 |
| Validation | 2020–2021 |
| Testing | 2022–2023 |
| Forecast information cutoff | 16:30, `America/New_York` |
| Predictor groups | Market; market + macroeconomic; market + sentiment; all predictors |
| Evaluation | Training-range-normalized MAE and RMSE, R², and matched persistence comparison |

ARIMA uses closing-index history only. GBM and LSTM can use eight market features, four macroeconomic features, and two news-sentiment features (14 predictors in total). Their different information sets mean this is a comparison of forecasting systems, not an isolated test of model architecture.

## Repository file

- `Financial_Forecasting_ARIMA_GBM_LSTM_Colab(1).ipynb` — executable Google Colab notebook containing preprocessing, model fitting, evaluation, plots, and result exports.

## Getting started

1. Open the notebook in [Google Colab](https://colab.research.google.com/), or upload it through **File → Upload notebook**.
2. For LSTM training, select **Runtime → Change runtime type → T4 GPU** when available.
3. Run the installation and configuration cells.
4. Start with `RUN_MODE = 'quick'` for a reduced software check. Use `RUN_MODE = 'full'` to enable the larger parameter grids and seed configuration.
5. Review the model flags, indices, horizons, predictor groups, and input-file paths before running the execution cells.
6. Run the notebook in order and inspect the exported predictions, metrics, figures, and environment manifest.

**Computational note:** Full execution can involve many model fits and require substantial time and memory. Successful execution and numerical reproduction have not been independently established for this release.

## Input data

The notebook supports a public-market-only mode using downloaded market series. To enable macroeconomic and sentiment predictors, place the following files in `/content/financial_inputs/`:

| File | Required fields | Purpose |
| --- | --- | --- |
| `reuters_headlines.csv` | `published_at`, `document_id`, `source`, `headline`, `language` | Licensed Reuters headlines with timezone-aware timestamps |
| `alfred_vintages.csv` | `series_id`, `date`, `vintage_date`, `value`; optional `release_timestamp` | Historical point-in-time macroeconomic vintages |
| `market_closes.csv` (optional) | `Date`, `^GSPC`, `^DJI`, `^IXIC` | Frozen closing-index snapshot instead of a fresh download |

The four macroeconomic series are `FEDFUNDS`, `CPIAUCSL`, `UNRATE`, and `INDPRO`. The notebook uses `ProsusAI/finbert` for headline sentiment when licensed headlines are supplied.

**Data restrictions:** The Reuters headline archive and original ALFRED vintage snapshot are not bundled. Users must obtain any restricted content through authorized sources. Freshly downloaded market data may differ from the study's October 1, 2026 extraction.

## Methods and safeguards

- Chronological partitions, with validation-based hyperparameter selection.
- Training-only scaling, including a separate target min–max transformation.
- Forecast-origin and target-date alignment.
- Point-in-time macroeconomic availability rules to reduce look-ahead bias.
- Timestamp-aware headline filtering, deduplication, and sentiment aggregation.
- ARIMA sequential state updates without repeated parameter fitting during evaluation.
- Retention of individual prediction records, aggregate scores, and run metadata.
- Last-value (persistence) benchmark for matched targets.

The notebook contains a 120-target S&P 500 diagnostic and a restricted 119-target persistence comparison. These should not be interpreted as a complete persistence evaluation across all indices and horizons.

## Outputs

Depending on the enabled models and available inputs, the notebook produces prediction records, aggregated error summaries, diagnostic and persistence comparisons, research figures, source information, and an environment manifest. Outputs are generated by execution; they are not supplied as independently validated results.

## Reproducibility and limitations

The manuscript reports aggregate one-session MAE of **0.021 (LSTM), 0.029 (GBM), and 0.056 (ARIMA)**, and RMSE of **0.034, 0.048, and 0.087**, respectively. These are **manuscript-reported reference values**, not verified notebook outputs. The manuscript also reports that a last-value forecast outperformed all three fitted methods on its matched 119-target subset.

Exact reproduction requires the original market snapshot, point-in-time macroeconomic data, licensed news corpus, software environment, experimental configuration, and prediction records. The public-market-only and quick configurations are not equivalent to the full manuscript evaluation. Historical application of a retrospectively selected FinBERT checkpoint also does not establish its availability at each historical forecast date.

No claim of exact result reproduction, statistical significance, or trading profitability is made by this repository.
